# SwiftUI app

Здесь находится пользовательский интерфейс iPhone-версии «С8 расчеты».

Текущий этап:
- главный экран;
- переход в «Расчёт прибыли»;
- три режима: «По дате», «До баланса», «До чистой прибыли»;
- ввод уровня, баланса, лидерских сигналов, VIP и L1.

Следующий этап — подключение формы к C8CalculationsCore и вывод результатов, затем модули структуры команды, дивидендов и OCR.
