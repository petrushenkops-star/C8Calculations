# С8 расчеты — iOS

Параллельная iPhone-версия Android-приложения. Android-код не изменяется.

## Статус
Первый этап: нативное Swift-ядро с теми же уровнями C1–C6, правилами сигналов, автопереходом уровней, прогнозом по дате и дивидендами. Контрольный расчёт дивидендов: 432 USDT за 10 дней для эталонной структуры команды.

Дальше: целевой баланс, целевая чистая прибыль, SwiftUI-интерфейс, сохранение данных, Vision OCR, Xcode-проект и CI-сборка iOS.
